## Attribution and rights status

The current archive filenames and Drive metadata do **not** establish individual photographer credits or licensing terms. Therefore, do not invent a photographer, claim public-domain status, or present a misleading public attribution. Before republishing under the final domain, check the owner's original licensing records for each legacy image. If an image requires credit, add the correct creator, source and license via the optional `photoCredits` slot in `AttractionDestinationPage`. If ownership cannot be established, replace it with a properly licensed, credited image.

This is an internal editorial audit, not a public visitor note.
